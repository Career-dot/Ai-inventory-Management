Overview

The RFPilot API lets you upload RFPs, trigger draft generation, and pull compliance matrices programmatically — useful if you want RFPilot embedded directly in your own CRM or proposal tool.

REST API

Predictable, resource-oriented endpoints returning JSON.

Webhooks

Get notified the moment a draft or compliance matrix is ready.

Authentication

Authenticate by sending your API key in the Authorization header on every request.

# Example request curl https://api.rfpilot.dev/v1/rfps \ -H "Authorization: Bearer YOUR_API_KEY"

Quickstart

Upload an RFP and request a first draft in two calls.

RFP objects

Every uploaded document becomes an rfp object containing parsed requirements, deadlines, and evaluation weighting.

Draft generation

Request a draft for any section, or the full document, referencing your connected content library.

Compliance matrix

Pull a structured compliance matrix at any point — useful for exporting to your own review tooling.

Webhooks

Subscribe to draft.completed, compliance.updated, and rfp.deadline_approaching events.

Rate limits

Growth and Enterprise plans get 600 requests/minute by default; contact us for higher limits.
